# Superstore Sales Analysis

Data cleaning, data modeling (Power Pivot, DAX), and what-if analysis using Superstore dataset (2015-2018). Tableau dashboards available separately.

## What's in this repo

| File | Description |
|------|-------------|
| `superstore(AutoRecovered).xlsx` | Main Excel file (data cleaning, Power Query, Power Pivot, DAX measures, what-if analysis) |
| `calender_superstore.xlsx` | Calendar table for time intelligence |
| `calender_superstore.hyper` | Calendar table (Tableau extract) |
| `fact_sales.hyper` | Fact sales table (Tableau extract) |
| `Ssuperstore.twb` | Tableau workbook |
